# Firecrawl / Alexandria 利用評価

更新日: 2026-09-30 JST

## 目的
わらしべAI Research LAB の技術調査・API/SDK仕様確認・GitHub Issue/PR・研究論文探索で、Firecrawl / Alexandria を通常のWeb調査と比較し、採用価値を小規模に評価する。

## 現在の扱い
- ChatGPT側では Firecrawl プラグインが利用可能。
- Alexandria は Firecrawl 経由の構造化データ探索候補として扱う。
- 本体コードの必須依存にはしない。
- Firecrawl / Alexandria の結果だけで実市場データ、成約事実、実取引許可、MAIN変更を確定しない。

## 初期評価対象
まず開発・研究用途のみで比較する。

1. Python/API/SDK の最新仕様確認
2. GitHub Issue / merged PR / README / 開発ドキュメント探索
3. AIエージェント、MCP、ガードレール等の論文探索
4. 既存実装・成熟OSS・公式SDKの再利用候補探索

商品価格・実成約データなど商取引判断への利用は、上記の評価後に別マイルストーンで検討する。

## 比較項目
同じ問いを通常Web調査と Firecrawl / Alexandria で調べ、次を記録する。

- 一次資料・公式資料への到達率
- 情報の鮮度
- URL・出典の追跡可能性
- 同じ問いでの再現性
- 調査時間
- 利用コスト / クレジット消費
- ノイズや重複の少なさ
- わらしべAIの開発判断への有用性

メール等に記載されたベンダー内部評価値は参考情報とし、採用判断の根拠にはしない。

## 安全条件
- 読み取り・検索・抽出を優先する。
- browser interaction、フォーム送信、外部書き込み等の副作用を伴う操作は、この評価の対象外。
- Secrets、実DB、実取引、決済、MAIN/production 変更を行わない。
- 重要な仕様は公式一次資料または独立した根拠で再確認する。
- プラグインが利用不能でも権限拡張や危険な迂回をせず、通常Web調査へフォールバックする。

## 採用判定
最低3件の異なる開発調査で比較し、Firecrawl / Alexandria が次のいずれかを安定して改善した場合に、Research LAB の標準調査候補へ昇格する。

- 一次資料への到達
- 調査時間
- 再現性
- ノイズ削減
- 開発判断に必要な根拠の明確さ

昇格後も、単独ソースを真実扱いしない。
